Metadatos en HTML

Los metadatos son información que se coloca dentro del documento HTML para describir características del documento como el autor, la descripción, las palabras clave o las instrucciones para motores de búsqueda y navegadores


Los metadatos se incluyen dentro de la etiqueta <head> del documento HTML, pero no se muestran directamente en la página web. Estos datos ayudan a los navegadores, motores de busqueda y aplicaciones a comprender mejor el contenido de la página.

Charset (Conjunto de carácteres)

Define el conjunto de carácteres utilizando el documento, como UTF-8, que soporta casi cualquier carácter

Viewpoint (Responsive Design)

Ayuda a configurar la visualización de una página web en dispositivos móbiles, garantizando que el contenido se adapte correctamente a diferentes medidas de pantalla

Descripción de la página

Proporciona una breve descripción de contenido de la página. Esta información es utilizada por los motores de búsqueda para mostrar descripciones en los resultados de búsqueda.

Palabras clave (Keywords)

Define un conjunto de palabras clave que describen el contenido de la página. Aunque no es tan utilizado por los motores de búsqueda actualmente, puede ser útil por otras aplicaciones.

Autor de la página

Indica el nombre del autor o la empresa responsable del contenido de la página web

Instrucciones para los bots de búsqueda

Indica a los motores de búsqueda como indexar y rastrar el contenido de la página.

Open Graph Tags (para redes sociales)

Los Open Graph Tags son metadatos utilizados por las redes sociales (como Facebook o Twitter) para mostrar previsualizaciones personalizadas cuando se comparte un enlace.

Metadatos para aplicaciones móbiles

Puedes utilizar metadatos para mejorar como se ve la página cuando se guarda a la pantalla de inicio de un dispositivo móbil

Favicon

Aunque no es un <meta>, el favicon es un metadato visual importante que se muestra en la pestaña del navegador

Lang(atributo)

El atributo "lang" se define dentro de la etiqueta <html> para especificar el idioma general de la página, o dentro de cualquier otra etiqueta HTML para marcar un idioma específico dentro de una parte del contenido.

IMPORTANTE

Buenas prácticas en el uso de metadatos en HTML

  1. Utiliza el conjunto de carácteres UTF-8 para garantizar que todos los carácteres especiales se muestren correctamente en todos los dispositivos y navegadores.

  2. Incluye una descripción relevante de la página para ayudar los motores de búsqueda a comprender mejor el contenido y mejorar su clasificación.

  3. Optimiza para móbiles utilizando la etiqueta viewport para asegurar que la página se adapte correctamente a diferentes dispositivos.

  4. Incluye Open Graph Tags si quieres que la página se muestre de manera atractiva cuando se comparten en redes sociales.

  5. Utiliza metadatos de bots para controlar como quieres que los motores de búsqueda indexen o no indexen la página.
