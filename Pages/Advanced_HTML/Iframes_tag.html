Etiqueta <Iframes>

<Iframe> (inline frame) es una técnica HTML que permite insertar una página HTML, dentro de otra página web. Es una manera más moderna y segura de incrustar contenido externo, como otras páginas web, vídeos, formularios o mapas, dentro de una página principal.


Los iframes se utilizan bastante para contenidos dinámicos como videos de Youtube, Google Maps, o integraciones de servicios externos


La etiqueta <iframe> se define dentro del cuerpo del documento y se puede personalizar con atributos como width, height, src y frameholder.

IMPORTANTE

  • Evita el uso excesivo de iframes, ya que puede hacer que la página sea más lenta y dificil de gestionar. Utilizalos solo cuando sea necesario.

  • Utiliza el atributo sandbox para seguridad cuando incrustas contenido de otros sitios. Este atributo permite limitar las acciones que el iframe puede realizar dentro del sitio web, mejorando la seguridad.

  • Optimiza la altura y anchura del iframe para asegurarte de que el contenido se vea correctamente en todas las medidas de la pantalla, especialmente en dispositivos móbiles.

  • Utiliza alternativas cuando sea posible: Cuando solo necesites cargar contenido dinámico que puedes generar tu mismo (como un vídeo o imagen), considera cargarlo directamente en la página en lugar de utilizar un iframe.

  • Utiliza allowfullscreen para vídeos. Esto permite que se puedan visualizar en pantalla completa, mejorando la experiencia de usuario (UX).
