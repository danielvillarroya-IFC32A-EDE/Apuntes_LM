la etiqueta <div> (abreviatura de "division") se utiliza para crear contenedores de bloques en una página HTML. Es una etiqueta de nivel de bloque, lo que significa que ocupa todo lo ancho disponible y comienza en una línea nueva.

    No tiene ningún significado semántico por si mismo; simplemente agrupa los demás elementos, como texto, imágenes u otras etiquetas, y suele ser estilizada con CSS

IMPORTANT

  1. Uno de los errores más comunes es el uso excesivo de <div> para cualquier cosa, cuando existen etiquetas semánticas más adecuadas como <header>, <section>, <article>, <footer>, etc...

  2. Utiliza <div> para agrupar elementos que forma una unidad lógica o visual dentro de la página, pero siempre que no haya una etiqueta semántica más adecuada.
