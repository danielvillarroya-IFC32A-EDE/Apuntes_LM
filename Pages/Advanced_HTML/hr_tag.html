Etiqueta <hr>

En HTML5, el uso de la etiqueta <hr> no es solo decorativo. Tiene un valor semántico para indicar un cambio de tema o una ruptura del flujo del documento, ayudando tanto a los motores de búsqueda como a las herramientas de accesibilidad para entender mejor la estructura del contenido.

IMPORTANTE

  • No abuses de la etiqueta <hr>, utilizala cuando sea necesario para separar secciones importantes o marcar un cambio de contenido.

  • Estiliza las líneas con CSS, aunque <hr> genera una línea por defecto, utiliza CSS para personalizar el aspecto y hacer que se ajuste al diseño de tu sitio web.

  • Uso semántico: Recuerda que <hr> se puede utilizar para indicar un cambio en el contenido o tema dentro de un documento, el cual tambien mejora la accesibilidad.

  • Evita utilizar <hr> para finalidades visuales solamente, si necesitas una línea solo para estilo, considera utilizar CSS en lugar de la etiqueta <hr> para mantener el documento limpio y semántico.
