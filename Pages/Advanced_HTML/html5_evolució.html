La evolución de HTML5

Es una evolución importante respecto a las versiones anteriores de HTML, introduciendo nuevas etiquetas y funcionalidades que permiten una mejor gestión del contenido multimedia, formularios avanzados y mejoras en al semántica en la página web.

Etiquetas nuevas de HTML5

  1. <section>: Usado para agrupar contenido relacionado dentro de una página

  2. <article>: Representa un bloque de contenido autónomo, como un artículo de un blog, una notícia o un post que puede existir independientemente del sitio web

  3. <aside>: Define contenido relacionado con el contenido principal pero no esencial. Normalmente se utiliza para las barras laterales, anuncios o información complementaria

  4. <header> y <footer>: Etiquetas para definir las cabeceras y pies de página.

  5. <nav>: Especifica para las barras de navegación de un sitio web.

  6. <figure> y <figcaption>: Agrupa elementos multimedia (como imágenes o vídeos) y sus descripciones.

IMPORTANTE

Buenas prácticas para utilizar los elementos de estructura

  1. Utiliza elementos semánticos para organizar mejor la página. Esto hace que sea más comprensible para los navegadores, buscadores y lectores de pantalla.

  2. Evita el uso excesivo de divs ("divitis") y aprovecha las etiquetas como <section>, <article>, y <aside> para hacer páginas más semánticas

  3. Proporciona enlaces de navegación claros dentro de los elementos <header> y <footer> para mejorar la experiencia de usuario y accesibilidad.

  4. No abuses de <aside>, ya que este elemento tiene que contener información complementária y no esencial para el contenido principal.
