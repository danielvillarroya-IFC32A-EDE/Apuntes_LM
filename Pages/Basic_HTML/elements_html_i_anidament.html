Elementos html y anidamiento

Diferencia entre Etiquetas i Elementos

Etiqueta (Tag)

  • Es la parte que define el inicio y el final de un componente HTML
  • Se delimita con los simbolos < >.

Ejemplo

Elemento

  • Un elemento incluye la etiqueta de obertura, el contenido (si hay) y la etiqueta de cierre.
  • Los elementos pueden ser vacíos o contener otros elementos dentro.

Ejemplo

Elementos anidados

  • Anidamiento se refiere a colocar un elemento HTML dentro de otro elemento
  • Es importante seguir correctamente el orden de las etiquetas: La primera que abre es la última que cierra
