Tablas básicas con HTML

Etiqueta <table>:

La etiqueta <table> define la tabla y actua como el contenedor principal.

Etiqueta <tr> (table row):

Define una fila dentro de la tabla.

Etiqueta <td> (table data):

Crea una celda dentro de una fila de la tabla (valores de la tabla).

Atributos de tabla

  1. border:

    • Añade un borde a la tabla y a las celdas.

  2. cellpadding:

    • Define el espacio entre el contenido de la celda y el borde de la celda.

  3. cellspacing:

    • Controla el espacio entre las celdas de la tabla.

Etiqueta <thead> (table head):

  • Define el encapsulamiento de la tabla, agrupando las filas de encapsulado (habitualmente las que contienen <th>.

Etiqueta <tbody> (table body):

  • Agrupa el cuerpo de la tabla, es decir, las filas de datos. Suele usarse para separar los datos de encapsulamiento.

Etiqueta <th> (table header):

  • Se utiliza para crear una celda de encapsulamiento en una tabla. El texto dentro de <th> aparece en negrita y centrado por defecto..

IMPORTANTE

Buenas prácticas:

  1. Utiliza <theas> y <tbody> para organizar las tablas, especialmente en tablas más grandes, con tal de separar claramente el encapsulamiento del cuerpo de la tabla.

  2. Mantén las tablas simples para datos tabulados y utiliza CSS para el diseño más avanzado de las tablas (colores, escala de la fuente, etc.).
