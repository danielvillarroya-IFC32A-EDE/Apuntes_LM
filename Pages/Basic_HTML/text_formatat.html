Texto formatado

<b> y <strong>: Negrita

<b> aplica negrita sin indicar importancia semántica

<strong> aplica negrita e indica que el texto es importante

<i> y <em>: Cursiva

<i> aplica cursiva sin implicar énfasis

<em> aplica cursiva con énfasis, indicando que el texto tiene importancia

<u>: Subrayado

Se utiliza para subrallar texto

<strike> o <s>: Texto rallado

Aplica un rallado al texto, indicando que está borrado o ja no es relevante

<sup>: Superíndice

Se utiliza para elevar el texto, como en exponentes matemáticos

<sub>: Subíndice

Se utiliza para poner el texto en posición de subíndice, utilizado normalmente en fórmulas químicas
