Etiqueta <center>

La etiqueta <center> se utilizava en las versiones antiguas de HTML para centrar el contenido dentro de una página web, tanto texto como imágenes u otros elementos.

Está obsoleta en HTML5, y se tendría que evitar su uso. En lugar de usar <center>, hoy en dia se usa CSS para centrar los elementos de manera eficiente.
