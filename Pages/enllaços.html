Enlaces en HTML

  • La etiqueta <a> se utiliza para crear enlaces a otras páginas webs, documentos, secciones dentro de la misma página o cualquier otro recurso.

  • El elemento esencial para los enlaces es el atributo href que define el URL a la cual redirige al usuario.

  • EL texto entre la etiqueta de apertura y la de cierre es el que el usuario verá y podrá clicar encima para ser redirigido.

Atributos de enlaces:

  1. href (hypertext reference):

    • Define la URL de destino del enlace.

    • Puede ser un enlace absoluto (una URL completa) o relativo (Un camino dentro del mismo dominio).

  2. target:

    • Define donde se abrirá el enlace (en la misma pestaña, en una nueva pestaña o una nueva ventana).

    • Los valores más habituales son:

      • _blank: Abre el enlace en una nueva pestaña.

      • _self: Abre el enlace en la misma pestaña (Es el valor predeterminado).

IMPORTANTE

Buenas prácticas:

  • Utiliza enlaces descriptivos en lugar de genéricos como "Clica aquí". Esto mejora la accesibilidad y SEO

    • Correcto: "Visita la página de Contacto"

    • Incorrecto: "Clica aquí"

  • Utiliza target="_blank" solo cuando sea realmente necesario, ya que abri enlaces en nuevas pestañas puede confundir a algunos usuarios.

  • Asegurate siempre que los enlaces sean accesibles añadiendo una descripción adecuada para usuarios con lectores de pantalla
