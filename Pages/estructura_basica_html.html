Estructura básica de html

  1. Un documento HTML se basa en una estructura jerárquica de etiquetas que definen las diferentes partes de la web. Como es una estructura jerárquica, en todos los documentos HTML se pueden ver elementos dentro de otros.

  2. Cada página HTML sigue una estructura similar, comenzando con el identificador
    <!DOCTYPE> y seguido de las etiquetas <html>, <head> y <body>.
