Formularios de HTML

Los formularios son una de las herramientas más importantes de HTML porque permiten a los usuarios enviar datos a un servidor con HTML5, los formularios han ganado nuevas funcionalidades que mejoran su usabilidad y validación.


Un formulario se crea con la etiqueta <form>, que actua como el contenedor que todos los elementos de entrada (texto, botones, secciones, etc.).


Cada campo del formulario se envia como datos a un servidor cuando el usuario lo envia



La etiqueta <input> es el elemento más versátil para crear campos de entrada. El tipus de campo se define con el atributo type



La etiqueta <label> se utiliza para etiquetar los campos de formulario y mejorar la accesibilidad



Para textos largos, como comentarios o descripciones, se utiliza <textarea>, que permite un área de texto más grande



<select> se usa para crear listas desplegables de selección. Cada opción dentro de la liste se define con <option>.



El atributo multiple para las listas desplegables de selección. Permite seleccionar múltiples opciones en una lista de selección.



Se utiliza para crear botones de envío u otras acciones dentro del formulario.



Radio buttons permiten seleccionar una opción de un conjunto de posibilidades



Las checkboxes permiten seleccionar diversas opciones independientes.




Validación de formularios

HTML5 introduce una serie de nuevos atributos y tipos de entrada para validar los formularios de manera nativa, sin la necesidad de JavaScript


Atributo required:

  • Marca un campo como obligatorio

Atributo pattern:

  • Permite definir un patrón con expressiones regulares para validar la entrada del usuario.


Tipos de entrada especiales

Estos tipos permiten validar y mostrar los campos de formulario de manera más adecuada según el tipo de datos que esperan obtener el usuario:

<input type="password">

<input type="email">

<input type="url">

<input type="tel">

<input type="number">

<input type="range">

<input type="date">

<input type="time">

<input type="datetime-local">

<input type="month">

<input type="week">

<input type="color">

<input type="file">


Buenas prácticas

  • Uso de la etiqueta <label> para mejorar la accesibilidad

  • Utiliza los tipos de entrada adecuados

  • Definir el atributo "required" para campos obligatorios

  • Añade la validación nativa con "pattern" y "min"/"max"

  • Usa "placeholder" para proporcionar pistas

  • Organiza los campos del formulario en grupos lógicos

  • Proporciona información clara sobre los errores

  • Utiliza "autocomplete" para mejorar la experiencia de usuario
