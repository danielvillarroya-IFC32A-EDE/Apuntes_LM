Multimedia con HTML

HTML5 introdujo maneras nuevas y eficientes de integrar multimedia en páginas web, incluyendo imágenes, vídeos y áudio sin necesidad de plug-ins (extensiones) externos como Flash. Esto mejoró tanto la compatibilidad como la usabilidad en múltiples dispositivos, especialmente en móbiles.

Imágenes en HTML

La etiqueta <img> se utiliza para insertar imágenes, esta es una etiqueta auto-cerrada, lo que significa que no tiene una etiqueta de cierre, ya que no pueden tener etiquetas anidadas dentro suya.

Atributos principales:

  1. src: Especifica la ruta de la imagen.
  2. alt: Proporciona un texto alternativo para la imagen, útil para la accesibilidad y SEO
  3. width y height: Controlan las medidas de la imagen



Vídeos en HTML5

Etiqueta <video>

  • HTML5 introduce la etiqueta <video> para insertar vídeos de manera nativa en la página web sin necesitar ningún plug-in externo.

  • Atributos principales:
    • src: Ruta del archivo de vídeo.
    • controls: Muestra los controles de vídeo (play, pause, volume, etc.).
    • autoplay: Hace que el vídeo se reproduzca automáticamente cuando se carga la página
    • loop: Hace que el vídeo se reproduzca en bucle
    • muted: Reproduce el vídeo sin sonido

Audio en HTML5

Etiqueta <audio>

  • De manera similar a los vídeos, HTML5 permite insertar audio nativo con la etiqueta <audio>
    • Atributos principales:
    • src: Ruta del archivo de audio.
    • controls: Muestra los controles de reproducción de audio (play, pause, volume, etc.).
    • autoplay: Reproduce automáticamente el audio al cargar la página.
    • loop: Hace que el audio se reproduzca en bucle.
    • muted: Reproduce el audio sin sonido inicialmente.

Buenas prácticas para integrar multimedia

  1. Proporciona formatos de archivos compatibles con los diferentes navegadores para audio y video (como MP4, WebM, OGG
  2. Utiliza el atributo "alt" para las imagenes para mejorar la accesibilidad y optimizar el SEO
  3. No hagas uso del atributo "autoplay" en audio y vídeo, ya que puede interrumpir la experiéncia de usuario, especialmente en dispositivos móbiles.
  4. Controla la medida de los archivos multimedia para evitar el tiempos de carga largos y mejorar la experiéncia de usuario.
