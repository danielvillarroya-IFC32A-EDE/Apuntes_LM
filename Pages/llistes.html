Listas en HTML

Listas no ordenadas (<ul>)

  1. Se utilizan para listas de elementos sin un orden específico.

  2. Los elementos se muestran con viñetas u otros símbolos antes de cada ítem.

  3. Cada elemento de la lista se define con la etiqueta <li> (list item)

Listas ordenadas (<ol>):

  1. Se utilizan para listas en el que el orden de los elementos es relevante.

  2. Los elementos se numeran automáticamente (1, 2, 3, etc.).

  3. Cada elemento de la lista también se define con <li>

Atributos de listas:

  1. Atribut type (para listas ordenadas <ol>):

    • Se puede utilizar para definir el tipo de enumeración en la lista:

      • 1: Números (predeterminado).

      • A: Mayúsculas.

      • a: Minúsculas.

      • I: Números romanos en majúsculas.

      • i: Números romanos en minúsculas.

    • Atribut start (para listas ordenadas <ol>):

      • Define el número o letra para comenzar la enumeración

IMPORTANTE

Buenas prácticas:

  • Utiliza las listas no ordenadas (<ul>) cuando el orden de los ítems no sea importante.

  • Utiliza listas ordenadas (<ol>) cuando el orden sea relevante.

  • Personaliza las listas segun las necesidades visuales o estilísticas utilizando los atributos adecuados.
