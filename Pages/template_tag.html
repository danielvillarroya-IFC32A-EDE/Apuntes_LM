Etiqueta <template>

La etiqueta <template> se utiliza para definir fragmentos de HTML reutilizables que no se muestran inmediatamente cuando la página se carga. El contenido dentro de un <template> no se agrega al documento hasta que se manipula explicitamente con JavaScript, cosa que puede crear plantillas que se pueden clonar e insertar al DOM (Document Object Model) de manera dinámica

Este elemento es ideal cuando se quiere tener estructuras HTML preparadas que podrás añadir en el documento en tiempo real, sin que estas sean rendidas o visibles inicialmente. Esto proporciona mucha flexibilidad por las aplicaciones dinámicas.

IMPORTANTE

  • Mantén las plantillas simples y modulares. Organiza tu código dentro de <template> de manera que puedas reutilizar facilmente estas plantillas en diferentes secciones de la página.

  • Clona plantillas con JavaScript. La etiqueta que no renderiza su contenido hasta que lo invocas con JavaScript, lo que da control total sobre cuando i como se tiene que añadir al DOM.

  • Utiliza plantillas para generar contenido de forma dinámica. Es muy útil en aplicaciones donde el contenido tiene que ser generado o actualizado en tiempo real, como listas, formularios o tarjetas de productos.

  • No incluyas contenido activo dentro del template. Los scripts u otros contenidos interactivos dentro del template no se ejecutaran hasta que el contenido sea agregado al DOM, así que asegurate de añadir los elementos interactivos cuando esté en el documento.
